## Результат

Проверка не подтвердила реальные ошибки модели из заданного списка. Команда ниже искала фразы **в поле `state.error`** и ограничивала каждый запрос `LIMIT 200`:

```sql
SELECT ... FROM part
WHERE json_extract(data,'$.state.status')='error'
  AND lower(coalesce(json_extract(data,'$.state.error'),'')) LIKE '%...%'
LIMIT 200;
```

Вывод `sqlite3`: `model-resolution`, `unknown variant`, `model not found`, `provider error`, `rate limit`, `429`, `context length`, `token limit` — **по 0 совпадений**. Совпадения в произвольном `data` оказались текстом документов, команд и обсуждений; их нельзя считать сбоями провайдера.

# ТЗ dcfg-80rgm U2c — реестр PM2: ship-post отключён
FILE: docs/PM2-PROCESSES.md

Цель: две строки таблицы о `ship-post` и `ship-post-events` (≈:99-100) не описывают курьера как работающий сервис. Курьер отключён владельцем 17.10 (эпик dcfg-hrkh5); процессов нет (`pgrep -fa '[s]hip-post'` пусто 18.10). Файл большой — найди строки через Grep `ship-post`, не читай файл целиком.
5 Whys: реестр говорит «online, почтальон доставки» → после отключения реестр не обновили. ADR: оставить строки (история), заменить статус и описание.

## Правки
1. Строка, начинающаяся с ``| `ship-post` |`` → ``| `ship-post` | — | stopped | отключён владельцем 17.10 (dcfg-hrkh5): доставка — сам агент по «GitHub напрямую» (`CLAUDE.md`); файлы `tools/bin/ship*` оставлены для отката |`` + те же оставшиеся ячейки (владелец/примечание), чтобы число ячеек строки не изменилось.
2. Строка ``| `ship-post-events` |`` → описание `остаток замены, отключён вместе с ship-post 17.10 (dcfg-hrkh5)`; число ячеек сохранить.
Слова «почтальон», «курьер» в этих двух строках не оставлять.

## Запреты
Только эти две строки. Остальное в файле не трогать. Без rm -rf, force-push, --no-verify.
